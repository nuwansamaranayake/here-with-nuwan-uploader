Privacy policy

Last updated: 13 November 2026

Here With Nuwan Uploader is a private tool that runs on the channel owner's own computer. It uses YouTube API Services to upload and manage videos on the Here With Nuwan YouTube channel.

Data the tool accesses

When the owner signs in with Google, the tool receives permission to upload videos and to manage the videos, thumbnails, captions and playlists of the signed-in YouTube channel. It reads the titles, descriptions and status of that channel's own videos.

How the data is used

The data is used only to publish and update the owner's own videos. It is not used for advertising, profiling or any other purpose.

Storage and sharing

The sign-in token is stored only on the owner's computer. No data is sent to any server other than Google's. No data is sold or shared with anyone.

Removing access

Access can be removed at any time on the Google security settings page: myaccount.google.com/permissions. Deleting the token file on the computer also ends access.

YouTube and Google terms

The tool uses YouTube API Services. By using it, the user agrees to the YouTube Terms of Service. Google's privacy policy is at policies.google.com/privacy.

Contact

Questions: through the About page of the Here With Nuwan YouTube channel.
